# Linux Commands Lab

## Overview
This repository contains basic Linux commands along with explanations and terminal screenshots.

## Commands Covered
- cat
- head
- tail
- tar
- wget
- chmod
- export

## Description

### cat
Used to display the contents of a file.

### head
Used to display the first few lines of a file.

### tail
Used to display the last few lines of a file.

### tar
Used to combine and compress files and folders.

### wget
Used to download files from the internet.

### chmod
Used to change file permissions.

### export
Used to create environment variables in Linux.
